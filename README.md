AuraBy — Aplicativo de Finanças Pessoais

Sobre o projeto

O AuraBy é um aplicativo de controle financeiro pessoal desenvolvido com o objetivo de ajudar os usuários a acompanhar suas finanças de forma simples, prática e organizada. A proposta é facilitar o controle do dinheiro, permitindo visualizar receitas, despesas e saldo em um só lugar.

Funcionalidades

Dashboard financeiro: visualização do saldo e resumo das finanças.

Controle de receitas: cadastro e gerenciamento de entradas de dinheiro.

Controle de despesas: cadastro e gerenciamento de gastos.

Gerenciamento de registros: adicionar, editar e excluir informações financeiras.
